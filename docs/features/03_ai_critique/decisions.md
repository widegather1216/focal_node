# [Decisions (ADR)] 03. On-Demand AI Critique & Editorial Export

### [ADR-01] 2단계 지연 분석 파이프라인 (경량 인덱싱 태깅과 심층 비평의 분리)
- **배경**: 1단계 폴더 인덱싱 시점에 수천 장의 사진에 대해 무거운 다중 패스 심층 비평(UniPercept 8B 6-Pass 채점/비평 + Gemma 4 2-Pass 번역/구조화)까지 전수 실행하면 초기 인덱싱이 수십 시간 지연됨.
- **결정**: 1단계 인덱싱에서는 검색에 필수적인 SigLIP 2 임베딩/제로샷 힌트와 Gemma 4 경량 캡션/태그(`generate_caption_and_tags`)만 추출하고, 고비용 심층 비평은 사용자가 선택한 사진에 대해서만 온디맨드로 수행한 뒤 `ai_analysis`에 영구 캐싱함.
- **영향**: 초기 인덱싱 속도를 유지하면서도 필요한 사진에 최고 품질의 2-모델 협업 전문 비평 제공.

### [ADR-02] 클라이언트 사이드 에디토리얼 PDF/Markdown 생성
- **배경**: 백엔드에서 PDF 렌더링 라이브러리(wkhtmltopdf 등)를 번들링하면 PyInstaller 용량 증가 및 OS 폰트 의존성 문제가 발생함.
- **결정**: 프론트엔드 `CritiqueDocumentModal`에서 브라우저 네이티브 폰트와 `jsPDF`를 활용하여 클라이언트 사이드로 PDF/Markdown을 생성함.
- **영향**: 사이드카 바이너리 경량화 및 화면에 보이는 매거진 타이포그래피와 동일한 PDF 출력 품질 확보.

### [ADR-03] 6-Way 정량 평점(`overall`/`iaa`/`iqa`/`ista`) 및 영문 원문(`critique_en`)의 DB 컬럼 정규화
- **배경**: UniPercept가 산출한 정밀 실수 점수를 `ai_analysis.critique` 텍스트 상단에 문자열로만 합쳐 저장하면, 프론트엔드가 취약한 정규식 파싱에 의존해야 하고 SQL 레벨에서 점수 기반 필터링이나 고득점 정렬이 불가능함.
- **결정**: `ai_analysis` 테이블에 `overall_score`, `iaa_score`, `iqa_score`, `ista_score` (`FLOAT`, 인덱스) 및 `critique_en` (`TEXT`) 컬럼을 정규화하여 분리 저장하고, 기존 사용자 DB는 `run_migrations()`에서 자동 파싱 백필을 수행함.
- **영향**: `02_search_curation` 도메인의 최소 평점 기반 스마트 앨범 필터링 및 비평 아카이브 고득점 정렬을 SQL 인덱스로 고속 수행 가능.

### [ADR-04] 미학 주도형 EXIF 적응적 종합 평점 모델(Adaptive Perceptual Scoring) 및 점수 가이드 모달 채택
- **배경**: 기존 단순 고정 선형 가중합(`0.4*iaa + 0.3*iqa + 0.3*ista`)은 UniPercept ISTA가 '구조/표면 질감 풍부도(Texture Richness)'를 측정한다는 특성을 간과하여, 배경 보케가 들어간 감성 인물 사진이나 미니멀리즘 풍경 사진이 텍스처 결핍으로 인해 부당하게 70점대로 감점되고, 반대로 약간의 모션 블러/노이즈가 있더라도 예술성과 구도가 뛰어난 감성 스냅이 기계적 화질(IQA) 감점으로 B컷 취급을 받는 심각한 왜곡이 발생함.
- **결정**:
  1. **EXIF 광학 적응형 4대 가중치**: 조리개($F$) 및 $\text{ISO}$ 메타데이터를 기반으로 [인물/감성($F \le 2.8$)], [풍경/건축($F \ge 5.6$)], [야경/스트리트($\text{ISO} \ge 1600$)], [표준 데일리] 4개 모드로 가중치를 동적 재배분하여 얕은 심도 사진의 질감 감점을 원천 차단함.
  2. **미학적 탁월성 보너스($\Delta_{\text{aesthetic}}$)**: $\text{IAA} \ge 75$ 및 $\text{IAA} > \text{IQA}$ 조건에서 미학과 화질 격차의 25% 비율을 감성 상쇄 보너스로 환급하여 명작 감성 스냅을 보호함.
  3. **기존 DB 자동 백필**: 기동 시 `run_migrations()`에서 `exif_metadata`와 조인하여 이미 평점이 존재하는 사진들의 `overall_score`를 새 수식으로 일괄 자동 재계산함.
  4. **스코어보드 UI 유지 및 점수 가이드 모달**: 스코어보드 본체는 기존 4개 프로그레스 바 UI를 100% 깔끔하게 유지하고, 상단에 `[?] 점수 산출 가이드` 버튼을 두어 `ScoringGuideModal`에서 사진학적 기준과 수식을 투명하게 안내함.
- **영향**: 사진 장르와 작가의 촬영 의도에 부합하는 정밀하고 신뢰도 높은 평점 산출, 비평 아카이브 정렬 정합성 확보, 사용자 친화적 설명 제공.
