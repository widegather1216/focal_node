# [Doc 3] 프론트엔드 아키텍처 및 UI/UX 설계

이 문서는 React 18, TypeScript, Tailwind CSS, Tauri API를 결합한 데스크탑 앱의 프론트엔드 설계 및 사용자 인터페이스(UI) 최적화 전략을 다룹니다.

---

## 1. 상태 관리 및 성능 최적화 전략

로컬 데스크탑 앱 환경에서 수만 장 이상의 대용량 사진 라이브러리를 끊김 없이(Jank-free) 탐색하기 위해 프론트엔드는 다음 두 가지 핵심 라이브러리로 상태를 분리해 관리합니다.

### 1.1. 서버 상태 관리 (TanStack Query)
* **목적:** 사이드카 백엔드 API로부터 불러오는 비동기 데이터를 캐싱하고 동기화합니다.
* **주요 역할:**
  * **무한 스크롤(Infinite Scroll):** 대량 사진 조회를 위해 페이징 데이터 캐싱 및 스크롤 위치 기반 추가 로딩 처리.
  * **검색 결과 관리:** 사용자가 텍스트 검색 시 실시간 유사도 검색 및 필터링 결과를 캐싱하여 불필요한 네트워크 요청 감소.
  * **상세 메타데이터 패치:** 특정 사진 클릭 시 EXIF 및 AI 분석 결과를 최신 상태로 유지.

### 1.2. 로컬 전역 상태 관리 (Zustand)
* **목적:** 컴포넌트 간 유기적으로 실시간 반영되어야 하는 UI 상태를 저장합니다.
* **주요 역할:**
  * **검색어 및 하이브리드 필터 조건:** (기종, 렌즈, ISO 범위, 촬영 연도 등) 상태 보유 및 동기화.
  * **다중 선택 상태 (`selectedPhotoIdsForExport`):** 다중 사진 내보내기 및 포트폴리오 비평 대상 관리.
  * **인덱싱 상태 감시:** Tauri Event 리스너로부터 전달받은 백그라운드 인덱싱 진행률(%) 및 현재 처리 중인 파일 정보 업데이트.

### 1.3. 렌더링 최적화: 가상 스크롤 (Virtual Scroll)
* **라이브러리:** `@tanstack/react-virtual`
* **이유:** 수천 장의 사진을 뷰포트 내에 전부 HTML DOM으로 로드하면 심각한 메모리 부족 및 프레임 드랍이 발생합니다.
* **해결책:** 뷰포트에 표시되는 영역의 이미지 요소만 DOM에 남겨두고 나머지는 절대 좌표 배치를 통해 메모리 점유를 최소화합니다.

## 2. UI/UX 워크플로우 디자인

### 2.1. 온보딩 (Empty State)
* **시나리오:** 처음 앱을 실행하여 데이터가 비어 있을 때 노출되는 화면입니다.
* **구성:**
  * 화면 중앙에 입체감 있는 유리 효과(Glassmorphism) 스타일의 `[ + 사진 폴더 추가 ]` 버튼 배치.
  * 해당 버튼 클릭 시 Tauri의 네이티브 파일 탐색기 창(`@tauri-apps/api/dialog.open` API)을 호출하여 로컬 폴더 경로를 가져옵니다.

### 2.2. 사이드바 (Navigation & Status)
* **구성:**
  * **메뉴 탭:** `[🖼️ Gallery]`, `[📊 Insights]`, `[❤️ Favorites]` 탭 제공.
  * **Folders 리스트:** 등록된 인덱싱 폴더 목록과 폴더 삭제(Unindex) 기능.
  * **인덱싱 진행 상태 패널:** Tauri 네이티브 이벤트 리스너(`@tauri-apps/api/event.listen`)를 등록하여 실시간 스트리밍 알림 수신 및 프로그레스 바 렌더링.

### 2.3. 메인 검색 및 갤러리 뷰 (Main Content)
* **구성:**
  * **상단 검색바:** 세련된 자연어 검색창 및 필터 아이콘(카메라 기종, 렌즈 기종, ISO, 셔터스피드, 촬영일자 필터 패널).
  * **하단 그리드:** 가상화 그리드로 정렬된 사진 리스트. 각 이미지 카드는 백엔드의 `GET /api/photos/{id}/thumbnail` 캐시 URL을 바인딩하여 지연 로드(Lazy Loading)합니다.
  * **다중 선택 모드:** 갤러리 상단 '선택 모드' 활성화 시 다중 체크박스를 노출하여 내보내기 또는 AI 비평을 수행할 수 있습니다.

### 2.4. 상세 정보 패널 (Deep Dive Panel)
* **시나리오:** 갤러리에서 사진 카드 클릭 시 우측에서 슬라이드 인(Slide-in) 형태로 등장하는 패널입니다.
* **구성:**
  * **고화질 렌더링:** RAW 파일인 경우에도 실시간 sRGB JPEG 디코딩 스트리밍 서빙.
  * **EXIF 배지 영역:** ISO, 셔터스피드, F값, 카메라 모델, 35mm 환산 화각 칩(Chip) 배지 시각화.
  * **유사 무드 찾기 (`✨ Similar`):** 클릭 시 해당 사진의 시각 임베딩 기반 K-NN 레퍼런스 검색을 실행.
  * **AI 비평 (`🤖 Critique`):** UniPercept 8B / Gemma 4 VLM 모델을 통한 사진 구도, 조명, 색감 전문 비평 렌더링.
  * **AI 캡션 에디터:** Gemma 4 생성 캡션/태그 편집 기능 및 `is_user_edited=true` 업데이트.

### 2.5. 장비 통계 인사이트 뷰 (`AnalyticsView`)
* **시나리오:** 사이드바 `[📊 Insights]` 탭 클릭 시 전환되는 대시보드 뷰.
* **구성:** `recharts` 라이브러리를 통해 카메라 바디, 렌즈 모델 점유율(도넛 차트), 화각(35mm 환산) 및 조리개 사용 분포(막대 차트)를 아름답게 렌더링.

### 2.6. 다중 내보내기 모달 (`ExportModal`)
* **시나리오:** 선택한 다수의 사진을 지정 폴더로 복사 추출할 때 노출되는 진행 상황 모달.
* **구성:** EventSource SSE 스트림으로 백엔드의 실시간 내보내기 파일 복사 프로그레스를 수신하여 렌더링.
